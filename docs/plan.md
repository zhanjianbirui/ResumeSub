# 计划：去掉主密码 + 界面优化（v0.5.0）

## 决定
- 档案继续用 AES-256-GCM 加密，但密钥由插件首次运行时自动生成，存在 `storage.local`，打开即用，不需要密码。
- 完全去掉主密码相关功能：解锁、上锁、自动上锁、输错冷却、"上锁后等待重试"的标签页记录、`alarms` 权限。
- 旧版档案（用主密码加密过的）无法自动读取。检测到旧版档案时，提示用户确认"清空并重新开始"，然后重新导入简历。

## 里程碑 1：后台去密码
- 重写 vault：自动生成密钥，只保留 `read / write / reset / status`，其中 status 返回 `ready` 或 `legacy`。
- 消息协议：删掉 `vault.setup / unlock / lock`、`prefs.*`；新增 `app.status`，返回 `{ legacy, hasProfile, resumeName }`；新增 `vault.reset`，只允许扩展页面调用。
- autofill.plan：没有档案时返回 `{ status: 'empty' }`，不再返回 `locked`；浮层提示"还没有档案：点击工具栏 ResumeSub 图标导入简历"。
- 删除 auto-lock、prefs、pending 和 retry 相关代码与测试；manifest 去掉 `alarms` 权限。

## 里程碑 2：界面
- **视觉**：统一的 CSS 设计变量（颜色、字号、间距、圆角）；卡片式布局；跟随系统切换深色模式；新增插件图标（16/32/48/128 像素 PNG）。
- **popup**（宽 340px）：
  - 顶部显示图标和名称；
  - 当前网站卡片：显示域名和是否已启用，一个按钮启用或停用；
  - 没有档案时，显示主按钮"导入简历开始使用"；
  - 底部链接：编辑档案、网站管理。
- **设置页**：
  - 左侧导航分 4 页：档案 / 导入简历 / 自动填写网站 / 数据与隐私，用 URL hash 定位，popup 可以直接跳到对应页；
  - 档案页按板块折叠成卡片，保存按钮固定在底部；
  - "数据与隐私"页包含说明和"清空所有数据"，清空前需要再次确认。

## 里程碑 3：验证
- 单元测试和类型检查；构建。
- 真实浏览器：截图 popup 和设置页（浅色、深色各一张）；重跑 4 个网申测试页，确认自动填写没有回归。
